# games

## Snake

Run the single-player JavaFX Snake game with:

```shell
mvn javafx:run
```

Use the arrow keys or WASD to steer. Eating food grows the snake and increases
the score; the snake wraps around the board edges. Hitting its own body ends
the round. Press Enter or Space to restart.

The existing Tic-Tac-Toe game remains available from
`pl.mikolaj.games.tictactoe.Main`.
